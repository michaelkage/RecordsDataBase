# RecordsDataBase

A lightweight, front-end web application designed to manage student and institutional records through distinct user portals. This project provides a clean separation of concerns between administrative management and student data access.

## 🚀 Features

* **Admin Portal (`AdminPortal.html`)**: A dedicated dashboard for administrators to view, add, modify, or delete student records.
* **Student Portal (`StudentPortal.html`)**: A secure and straightforward interface for students to access their individual profiles, grades, schedules, or personal details.

## 🛠️ Technology Stack

* **HTML5**: Structured layouts for portal interfaces.
* **CSS3** *(Planned/Extension)*: Responsive styles for modern desktop and mobile layouts.
* **JavaScript** *(Planned/Extension)*: Local storage management or dynamic API integrations for processing records.

## 💻 Getting Started

### Prerequisites
To run this application locally, you only need a modern web browser (e.g., Google Chrome, Mozilla Firefox, Microsoft Edge, Safari). No complex backend servers or database installations are required for the initial front-end testing.

### Installation & Usage
1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/michaelkage/RecordsDataBase.git
   ```
2. Navigate into the project directory:
   ```bash
   cd RecordsDataBase
   ```
3. Open either portal directly in your browser:
   * Double-click `AdminPortal.html` to launch the admin panel.
   * Double-click `StudentPortal.html` to launch the student view.
